# Project Cover & Hero Media Types Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a dedicated `cover` thumbnail field and an `image`/`video`/`youtube` type choice for `heroMedia` to Strapi's `Project` content-type, and wire both through the site's front-end.

**Architecture:** Three new scalar/media attributes on the existing `Project` content-type (no new content-type). The front-end's `Project` type/mapper picks them up, `ProjectPage.tsx`'s hero-building logic switches on the new `heroMediaType` field instead of sniffing mime type, and both `ProjectPage.tsx` and `WorkPage.tsx` gain the same `cover → heroMedia (if image) → placeholder` thumbnail fallback chain.

**Tech Stack:** Strapi 5.52.2 (SQLite dev DB) in `pixelwave-cms`; React 19 + TypeScript + Vite in `000_sito`. No test runner in either repo (confirmed: `000_sito/package.json` has no vitest/jest) — verification is `tsc --noEmit`, `oxlint`, and live browser/curl checks, matching every prior sub-project in this codebase.

## Global Constraints

- **Repos:** backend changes go in `/Volumes/ups tl/02 pixelwave/00_pixel/pixelwave-cms`; frontend changes go in `/Volumes/ups tl/02 pixelwave/00_pixel/000_sito`. Separate git histories — commit each repo independently.
- **Field names (exact, from the approved spec):** `cover` (media, single image), `heroMediaType` (enumeration: `image`/`video`/`youtube`), `heroMediaYoutubeUrl` (string). `heroMedia` and `galleryImages` are unchanged.
- **Front-end naming:** the `Project` interface exposes `cover`, `heroMediaType` (same names) and `heroYoutubeUrl` (shortened from `heroMediaYoutubeUrl`, same convention as `description`→`desc`).
- **Fallback chain (both `WorkPage.tsx`'s grid thumbnail and `ProjectPage.tsx`'s `thumb`):** `cover` → `heroMedia` (only when `heroMediaType === "image"`) → the existing Picsum placeholder pattern for that call site. Never leave a blank thumbnail.
- **YouTube parsing fails soft:** an empty or unparseable `heroYoutubeUrl` when `heroMediaType === "youtube"` falls back to the existing placeholder-image `MediaItem`, not an error state.
- **YouTube hero gets the full scroll-pin treatment**, same as image/video — rendered as a chromeless iframe (`autoplay=1&mute=1&loop=1&playlist={id}&controls=0&playsinline=1`) inside the existing `ProjectVideoPinned`/`ProjectVideoAmbient` wrappers, unchanged structurally.
- **Existing projects are backfilled**, not left blank: `heroMediaType` set to match each project's *current* `heroMedia` mime type (`video` if `heroMedia.mime` starts with `video/`, else `image` — including when `heroMedia` is `null`, which resolves to `image`).

```typescript
// Backfills heroMediaType (new field) for every project that already
// exists in this dev database but predates the field, matching each
// project's current heroMedia mime type so nothing changes visually.
// Safe to delete once run; re-running is harmless (recomputes the same
// value from heroMedia every time).
//
// Mirrors seed.ts's own bootstrap pattern (see its header comment for why
// createStrapi/.load() is used instead of the strapi console CLI). Wrapped
// in a single top-level IIFE — with no top-level import/export, TS treats
// every .ts file under scripts/ as one shared global script rather than
// separate modules, so a second file with its own top-level `const
// compileStrapi`/`function run` collides with seed.ts's identically-named
// ones (confirmed: running a sibling script without this wrapper fails
// with "Cannot redeclare block-scoped variable 'compileStrapi'", pointing
// at seed.ts). Nesting everything inside the IIFE keeps those names
// block-scoped instead of global, without needing real import/export
// syntax (which would flip Node's module-format auto-detection between
// CommonJS and ESM and break the plain require() calls below).
;(async () => {
  const { compileStrapi, createStrapi } = require('@strapi/strapi');

  const appContext = await compileStrapi();
  const app = await createStrapi(appContext).load();
  app.log.level = 'error';

  const projects = await app.documents('api::project.project').findMany({
    populate: ['heroMedia'],
    fields: ['documentId', 'title'],
  });

  for (const project of projects) {
    const heroMediaType = project.heroMedia?.mime?.startsWith('video/') ? 'video' : 'image';
    await app.documents('api::project.project').update({
      documentId: project.documentId,
      data: { heroMediaType },
      status: 'published',
    });
    console.log(`Backfilled "${project.title}" -> heroMediaType: ${heroMediaType}`);
  }

  console.log(`Done — ${projects.length} project(s) updated.`);
  await app.destroy();
  process.exit(0);
})().catch((err) => {
  console.error(err);
  process.exit(1);
});
```

```typescript
/** Extracts an 11-character YouTube video id from any normal URL shape
 *  editors are likely to paste: a watch URL (`?v=ID`, optionally with
 *  other query params before/after), a shortened youtu.be/ID link, or an
 *  existing /embed/ID link. Returns null on anything else, so callers can
 *  fail soft to the placeholder image rather than rendering a broken
 *  embed. */
function parseYoutubeId(url: string): string | null {
  const match = url.match(/(?:youtu\.be\/|youtube\.com\/(?:embed\/|watch\?(?:.*&)?v=))([A-Za-z0-9_-]{11})/)
  return match ? match[1] : null
}
```

```typescript
function withMedia(p: Project): ProjectWithMedia {
  const placeholderHero: MediaItem = {
    type: "image",
    src: `https://picsum.photos/seed/pixellwave-${p.id}-hero/1600/900?grayscale`,
  }

  let hero: MediaItem
  if (p.heroMediaType === "youtube") {
    const videoId = p.heroYoutubeUrl ? parseYoutubeId(p.heroYoutubeUrl) : null
    hero = videoId ? { type: "youtube", videoId } : placeholderHero
  } else if (p.heroMediaType === "video") {
    hero = p.heroMedia ? { type: "video", src: p.heroMedia.url } : placeholderHero
  } else {
    hero = p.heroMedia ? { type: "image", src: p.heroMedia.url } : placeholderHero
  }

  const gallery: MediaItem[] =
    p.galleryImages.length > 0
      ? p.galleryImages.map((m) => ({
          type: m.mime.startsWith("video/") ? ("video" as const) : ("image" as const),
          src: m.url,
        }))
```
